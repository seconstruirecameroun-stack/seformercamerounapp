# Les pronoms personnels — script verrouillé

Leçon : Les pronoms personnels (CE1)
Registre : typographique. Rien n’est généré, tout est composé.
Voix : Céline, articulation claire, débit posé.

Fil conducteur : Un nom s’en va, un petit mot prend sa place.

## Narration

1. Le pronom est un mot qui remplace le nom.
2. Maman va au champ devient elle va au champ.
3. Les pronoms personnels sont je, tu, il, elle, nous, vous, ils, elles.

3. liste — {"mots": ["je", "tu", "il", "elle", "nous", "vous", "ils", "elles"], "colonnes": 4}
